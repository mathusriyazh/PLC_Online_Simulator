Parallel Branch Operation

Create a branch and drag its START and END handles to position the branch on the main ladder line.

Series = AND     Parallel = OR

Example: Y0 = ((X0 AND X3) OR (X1 AND X2)) AND X4

When one parallel path is TRUE, the branch is TRUE.

How to use

Step 1
Click a rung to select it.

Step 2
The selected rung is highlighted in cyan.

Step 3
Click NO, NC, COIL, TON, CTU etc.

Step 4
The new component will be added to the selected rung.

Step 5
Click Parallel Branch to add a branch to the selected rung.

Step 6
Drag the orange START and END handles.

Step 7
Toggle X0, X1 etc.

Step 8
Press RUN.
